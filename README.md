# Meu primeiro repositório
Este é o meu primeiro projeto que enviei para o Github.

## Como enviar projetos para o Github
- Precisaa ter o *GIT* e o **Github Desktob**
- Abrir o **CMD** na pasta do projeto e executar o comando: `git init`
- Fazer o **commit** no Gihub Desktop e depois clicar em `push` para enviar
    - Se é a primera vez, clicar em `publish`
    - Lembarar de, preferencialmente, dexar o projeto como **public**

    ## Como baixar projetos
    Abrir o **CMD** e digitar `git colne [ link do repositório]`
